EDU OPS / SaaS for learning centers

EDU OPS helps learning centers run their education operations.

EDU OPS is a multi-tenant SaaS management platform for learning centers. The application helps each center manage classes, students, teachers, schedules, homework, learning materials, salary operations, reports, audit timelines and notifications in a private tenant workspace.

Purpose of the application

The purpose of EDU OPS is to centralize daily learning-center operations so administrators, academic staff, teachers, students and accountants can coordinate class work, homework, documents and notifications securely.

Google Gmail connection

Tenant administrators may connect a Gmail account so EDU OPS can send notification emails for their own center. EDU OPS requests only openid, email and gmail.send. EDU OPS uses Gmail access only to send tenant notification emails and does not read, search, modify or delete Gmail mailbox content.
