EDU OPS Privacy Policy

Last updated: 12 August 2026

Information we process

EDU OPS processes account, tenant, class, student, teacher, schedule, homework, material, notification and operational data provided by users of each learning center.

Google OAuth data

When a tenant administrator connects Gmail, EDU OPS requests openid, email and https://www.googleapis.com/auth/gmail.send.

The Google data EDU OPS receives is the connected account's email address, Google account identifier, granted scopes and OAuth token material. EDU OPS uses this data only to identify the selected sender and send tenant notification emails such as homework assignments, document updates, review results and operational messages.

EDU OPS does not request permission to read, search, download, modify or delete Gmail messages, labels, contacts or Google Drive files.

Token storage and security

EDU OPS stores only the Google refresh token required for background email delivery. The refresh token is encrypted before storage. Access tokens are used in memory and are not intentionally stored.

Sharing, human access and advertising

EDU OPS does not sell, rent or transfer Google user data to advertising platforms, data brokers or information resellers. Google user data is not used for advertising, retargeting, credit decisions, or training generalized artificial intelligence or machine-learning models.

EDU OPS does not allow humans to read Google user data except when necessary for security, legal compliance, or support that the user explicitly requests and authorizes. Tenant data is not shared with other tenants.

Retention and deletion

The encrypted refresh token and connection metadata are retained while the tenant's Gmail connection remains active. Tenant administrators can disconnect Gmail inside EDU OPS to delete local token material. Gmail owners can also revoke access from Google Account permissions at any time.

Google API Services User Data Policy

EDU OPS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
